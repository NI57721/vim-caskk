*caskk.txt*  Japanese input method for Vim HEAD                       *caskk*

Caskk requires Vim HEAD.  Install it on 'runtimepath' and run :helptags for
its doc directory.  No input scheme or mappings are installed automatically.

GETTING STARTED                                             *caskk-start*

In your Vim9 configuration: >vim9

    import autoload 'caskk.vim' as Caskk
    Caskk.RegisterInputScheme({
      name: 'example',
      consonants: {k: 'k', n: 'n'},
      combinations: {a: 'a', i: 'i', u: 'u', e: 'e', o: 'o'},
      specials: {nn: 'ん'},
    })
    Caskk.Config({
      dictionaries: ['/path/to/SKK-JISYO.utf8'],
      state_path: expand('~/.local/share/caskk/state.jsonl'),
      state_auto: true,
      sticky_key: ';',
      mappings: {"\<Space>": 'Convert', "\<C-P>": 'PreviousCandidate',
        "\<F10>": 'Commit'},
    })
    inoremap <C-J> <ScriptCmd>Caskk.Toggle('example')<CR>
    cnoremap <C-J> <ScriptCmd>Caskk.Toggle('example')<CR>
<
Replace the dictionary path with an existing file.  This is a minimal input
scheme: 'ka' inserts か; 'Ka' or ';ka' starts a reading for conversion.  Space
converts, CTRL-P returns from the first candidate to the reading, and F10 commits.

Reference: |caskk-api|, |caskk-input-schemes|, |caskk-config|,
|caskk-config-mappings|.

PUBLIC FUNCTIONS                                            *caskk-api*

Import autoload 'caskk.vim' as Caskk.  In legacy Vim script, use the corresponding
caskk#Function() name.  Functions below return no value unless noted.

RegisterInputScheme(definition)                  *caskk-register-input-scheme*
    Registers or replaces a named input scheme; see |caskk-input-schemes|.
    Successful registration disables active Caskk input.  Enable it again.

GetInputScheme(name) -> CompiledScheme                *caskk-get-input-scheme*
    Returns the compiled scheme.  An unknown name raises an error.

Enable(name)                                                *caskk-enable*
    Enables the named scheme in the current buffer, or current outermost
    :, / or ? command line.  Already enabled input is left as it is.

Disable()                                                  *caskk-disable*
    Finishes pending input and restores the previous mappings in this buffer
    or command line.  Does nothing when disabled.

Toggle(name)                                                *caskk-toggle*
    Disables enabled input; otherwise enables the named scheme.

IsEnabled() -> bool                                     *caskk-is-enabled*
    Reports whether Caskk is enabled in the current buffer or command line.

Config(options)                                             *caskk-config*
    Applies |caskk-settings|.  Omitted options reset to defaults; Config({})
    resets all settings.  Invalid options raise an error and retain the
    previous configuration.  Changing input settings disables active input;
    call Enable(name) again.  Dictionary-only reloads keep input enabled.

GetDictionaryLoadStatus() -> dict<string>      *caskk-dictionary-load-status*
    Returns {state: 'loading'/'ready'/'error', error: message}.
    Large dictionaries load in the background; error is empty unless loading
    failed.  A failed reload keeps the previous dictionaries available.

Reconvert() -> bool                                    *caskk-reconversion*
    From Normal mode, reopens a recent conversion beginning at the cursor.
    Enters Insert mode on success; returns false if no match is available.
    Example: >vim9
        nnoremap <Leader>r <ScriptCmd>Caskk.Reconvert()<CR>
<
LoadState()                                            *caskk-load-state*
    Loads user entries and preferences from state_path, replacing current
    in-memory state.  An unreadable or invalid file raises an error.

SaveState()                                            *caskk-save-state*
    Saves user entries and preferences to state_path.  Both LoadState() and
    SaveState() require a nonempty path.  The state file is internal data;
    use ExportUserDictionary() for an SKK dictionary.

ExportUserDictionary(path)                  *caskk-export-user-dictionary*
    Exports registered user entries as a UTF-8 SKK dictionary.  Learning and
    ranking preferences are excluded.  path must be a nonempty string.

OpenRegistration()                              *caskk-open-registration*
    Opens a pending registration request in Insert mode.  Useful with
    registration_auto: false.  See also the OpenRegistration action.

Custom registration UI functions ~

GetRegistrationRequest() -> Request/null_object  *caskk-registration-request*
    Returns the pending request, or null_object.  String fields: reading,
    okuri (full suffix), exact_okuri (first suffix character), lookup_key.

CompleteRegistration(text [, annotations])     *caskk-complete-registration*
    Registers and commits a nonempty candidate body; omit its okuri suffix.
    annotations is a list of strings, default [].

CancelRegistration()                            *caskk-cancel-registration*
    Cancels the request and returns to the editable reading.

Call completion/cancellation in the original buffer in Insert mode, for example
from a <ScriptCmd> mapping.  Both require a pending request.

INPUT SCHEMES                                        *caskk-input-schemes*

RegisterInputScheme() takes these fields:

name                                                  *caskk-scheme-name*
    Required string used by Enable(), Toggle(), and GetInputScheme().

consonants                                      *caskk-scheme-consonants*
    Required dictionary of input sequences to kana consonant identifiers,
    e.g. {k: 'k', j: 'ky'}.  'N' and 'T' produce ん and っ directly.

combinations                                  *caskk-scheme-combinations*
    Required dictionary of single keys to kana output sequences, e.g.
    {a: 'a', l: 'o*N'}.  The first vowel combines with a preceding consonant;
    'jl' in the examples produces きょん.  '*' sets an optional okuri boundary.

specials                                            *caskk-scheme-specials*
    Optional dictionary of input sequences to arbitrary text, e.g.
    {nn: 'ん', zx: 'い*くらい'}.  Specials take precedence over generated rules.
    In output, '*' marks an okuri boundary; '\*' and '\\' escape '*' and '\'.

Keys use ordinary characters or actual Vim keycodes such as "\<C-K>".
Combination values use kana symbols, not literal kana; special values use text.
Only one unescaped '*' is allowed in an output pattern.

Kana symbols                                           *caskk-kana-table*
    Vowels: a i u e o.  Direct symbols: N (ん), T (っ).
    Consonant identifiers: '' (vowels), x, xy, xw, k, ky, g, gy, s, sy,
    z, zy, t, ty, ts, th, d, dy, dh, n, ny, h, hy, f, b, by, v, p, py,
    m, my, y, r, ry, w, wh.  For example, k + a is か; ky + a is きゃ.

Matching                                        *caskk-special-matching*
    A special waits while a longer match is possible; there is no timeout.
    A combination key without a consonant stays literal, except a plain vowel.

BASIC USE                                                  *caskk-input*
                                                  *caskk-modified-input*
                                                             *caskk-okuri*

Uppercase or sticky input starts an editable reading (Modified input).
A further Modified syllable starts okuri: KaKu gives か*く and converts it.
The displayed '*' marks the okuri boundary and is not inserted into the text.

BS (including CTRL-H) removes pending keys, then okuri, its empty boundary, and reading characters.
By default, deleting the last item keeps Modified input; another BS cancels it.
See |caskk-config-keep-preedit-on-backspace|.  With a selected candidate, BS
returns to the reading and deletes one item.  Enter commits preedit; leaving
Insert mode finishes input.  Undo follows |caskk-config-undo-revert-to-reading|.

Completion                                            *caskk-completion*
    Reading suggestions appear automatically.  ShowCompletion selects one;
    NextCandidate/PreviousCandidate navigate, Commit accepts, CancelCompletion
    restores the reading.  Typing with a selected suggestion accepts it first.
    Available in Insert input, excluding inline registration.

Registration                                        *caskk-registration*
    Missing words open registration by default.  Enter registers the candidate
    body; Escape cancels.  Enter '本文;注釈' to register an annotation; only
    the first ';' separates fields.  Input modes are unchanged.  With inline registration, Escape during candidate
    selection first commits that candidate into the draft.

Command-line input                                   *caskk-commandline*
    Enable it separately in :, / or ?.  Enter commits pending input; press it
    again to execute.  Registration, reading completion, and reconversion are
    unavailable in command-line input.

Abbreviation mode                               *caskk-abbreviation-mode*
    Uses typed text directly as the dictionary reading.  Enter keeps the typed
    abbreviation literally; use Commit to accept completion or Convert for
    dictionary conversion.  Committing returns to the previous input mode.

Numeric conversion                              *caskk-numeric-conversion*
    Digit runs also search '#' dictionary keys.  Candidate placeholders:
    #0 ASCII, #1 fullwidth, #2 kanji digits, #3 positional kanji, #5 daiji,
    #6 Roman numerals, #8 comma grouping.  For example, '#:# /#0時#0分/'
    converts abbreviation '12:34' to '12時34分'.

Experimental dictionary entries ~

Adjective stems                                        *caskk-experimental-adj*
    An SKK entry such as 'うつくし /美し;@adj/' supplies okuri candidates:
    うつくし*く becomes 美しく.  The candidate popup shows ［adj］.

Verb stems                                            *caskk-experimental-verb*
    Add a tagged stem dictionary through dictionaries.  For example,
    'たべ /食べ;@verb-1-shimo-b/' converts たべ*る to 食べる.
    Its popup row shows ［verb］.
    Verb-only stems are omitted from reading completion and usually require
    okuri; registered complete finite forms can also convert without it.

In registration annotations, type @ to complete a label with a Japanese
explanation.  Type characters in order to filter (e.g. @v5 matches @verb-5-*).
Use Up/Down or Tab/Shift-Tab to select,
and Enter to insert it; another Enter registers the word.  Esc closes only
label completion.  Requires candidate_popup.  This works in both registration
windows and inline registration.

Tags also apply to user entries registered with okuri.  Tagged candidates
follow dictionary configuration order, just like ordinary candidates.
These entries append the entered okuri unchanged.  Pin, demotion, and learning
are shared across the stem's conjugations.  Markers appear only in candidate popups.

SETTINGS                                                *caskk-settings*

Pass these options to Config().  Defaults are shown beside each type.
Keep all desired options in each call; omitted options reset to defaults.

sticky_key                                      *caskk-config-sticky-key*
    string, ''.  Marks the next key as Modified, like uppercase input.
    Use a printable character such as ';' or a named key such as '<F9>'.

keyboard_layout                            *caskk-config-keyboard-layout*
    string, 'US'.  Shifted-symbol layout: 'US' or 'JIS'.

keyboard_layout_overrides         *caskk-config-keyboard-layout-overrides*
    dict<string>, {}.  Unshifted key to shifted character, e.g. {1: '?'}.
    Keys and values must be single printable characters; values must be unique.

mappings                                          *caskk-config-mappings*
    dict<string>, {}.  Key to action name; see |caskk-actions|.
    Use actual keycodes: {"\<Space>": 'Convert', "\<F10>": 'Commit'}.

small_tsu_okuri_as_t                   *caskk-config-small-tsu-okuri-as-t*
    bool, true.  Okuri starting with っ uses the SKK lookup prefix 't'.
    Set false to use 'x'.

keep_preedit_on_backspace       *caskk-config-keep-preedit-on-backspace*
    bool, true.  BS deleting the last reading item keeps empty Modified input.
    Another BS cancels it without deleting confirmed text.  Set false to end
    preedit as soon as the last item is deleted.

undo_revert_to_reading              *caskk-config-undo-revert-to-reading*
    bool, true.  Undo after conversion restores the reading; another removes
    it.  Set false to undo the whole conversion in one step.

persist_input_mode                    *caskk-config-persist-input-mode*
    bool, false.  Keeps the input mode across Insert sessions in the buffer.

dictionaries                                *caskk-config-dictionaries*
    list, [].  Read-only SKK sources in candidate priority order.  Each item
    is a UTF-8 path or {path: '/path/to/SKK-JISYO', encoding: 'euc-jp'}.
    Call Config() again to reload changed files.

state_path                                     *caskk-config-state-path*
    string, ''.  User-state file for LoadState(), SaveState(), and state_auto.
    Parent directories are created when saving.

state_auto                                     *caskk-config-state-auto*
                                                      *caskk-state-auto*
    bool, false.  Loads state on first Enable(), then saves changes and at
    exit.  Requires state_path.  A missing file starts with current user state.

registration_auto                       *caskk-config-registration-auto*
                                               *caskk-registration-auto*
    bool, true.  Opens registration automatically when candidates run out.

registration_prefill                 *caskk-config-registration-prefill*
                                            *caskk-registration-prefill*
    bool, true.  Prefills registration with the reading.

registration_inline                   *caskk-config-registration-inline*
    bool, false.  Uses an inline popup instead of a registration window.
    Left/Right move in the draft; BS/Delete edit it; Enter registers it.

register_mode_conversions          *caskk-config-register-mode-conversions*
    bool, true.  Adds text committed by kana/fullwidth mode actions to the
    user dictionary.  Set false to commit without registration.

completion_min_length                *caskk-config-completion-min-length*
    positive number, 2.  Minimum reading length for completion.

candidate_popup                           *caskk-config-candidate-popup*
    bool, true.  Shows candidate lists.  Disabling also stops automatic
    completion; ShowCompletion remains available.  ★ marks pinned candidates,
    ↓ marks demoted candidates.

mode_popup                                     *caskk-config-mode-popup*
    bool, true.  Shows the input mode near the cursor.

mode_popup_labels                       *caskk-config-mode-popup-labels*
    dict<string>.  Optional replacements for the default mode labels:
    {hiragana: 'あ', abbreviation: 'ab', katakana: 'ア',
     halfwidth_katakana: 'ｱ', fullwidth_alphanumeric: 'Ａ'}.
    Values must be nonempty; omitted labels keep their defaults.

mode_popup_markers                     *caskk-config-mode-popup-markers*
    dict<string>.  Defaults: {modified: '▽', candidate: '▼'}.
    An empty value hides that marker; omitted markers keep their defaults.

mode_popup_time                           *caskk-config-mode-popup-time*
    nonnegative number, 0.  Milliseconds before the mode popup hides.
    Zero keeps it visible until cursor movement or input ends.

highlight.preedit                               *caskk-config-highlight*
    dict<string>.  Preedit highlighting; term, cterm, gui default to
    'underline'.  Accepts |highlight-args| attributes and string fields
    ctermfg, ctermbg, ctermul, guifg, guibg, guisp, font, start, stop.
    Example: {highlight: {preedit: {gui: 'bold', guifg: '#123456'}}}.

MAPPING ACTIONS                                          *caskk-actions*

Assign these names through mappings.  No action keys are assigned by default.

Convert                                           *caskk-action-convert*
    Converts the reading; during selection, advances to the next candidate.

NextCandidate                              *caskk-action-next-candidate*
    Selects the next candidate.  Passing the last conversion candidate
    requests registration.

PreviousCandidate                      *caskk-action-previous-candidate*
    Selects the previous candidate; before the first, restores the reading.

Commit                                             *caskk-action-commit*
    Accepts the selected completion, conversion candidate, or reading.

ShowCompletion                            *caskk-action-show-completion*
    Opens completion and selects the first item, or advances the selection.

CancelCompletion                        *caskk-action-cancel-completion*
    Closes completion and restores the reading.

OpenRegistration                        *caskk-action-open-registration*
    Opens a pending registration request when automatic opening is disabled.

TogglePin                                      *caskk-action-toggle-pin*
    Toggles the selected candidate's pinned preference (ranks first).

ToggleDemote                                *caskk-action-toggle-demote*
    Toggles the selected candidate's demotion (ranks after normal candidates).

DeleteUserEntry                          *caskk-action-delete-user-entry*
    Removes a selected user entry after y/N confirmation.  System dictionary
    candidates remain available.  Not available in command-line or completion.

AbbreviationMode                        *caskk-action-abbreviation-mode*
    Uses literal input as the dictionary reading.

KatakanaMode                                *caskk-action-katakana-mode*
    Switches to katakana, or commits a hiragana preedit as katakana.

HalfwidthKatakanaMode              *caskk-action-halfwidth-katakana-mode*
    Switches to halfwidth katakana, or commits a hiragana preedit in that form.

FullwidthAlphanumericMode      *caskk-action-fullwidth-alphanumeric-mode*
    Switches to fullwidth alphanumeric input, or commits an abbreviation in
    that form.  Repeating the current non-hiragana mode returns to hiragana.
