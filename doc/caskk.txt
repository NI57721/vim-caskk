INTRODUCTION                                                *caskk-introduction*

I wanted to get the conversion I intended even without looking at the screen.
That's what led me to develop this IME.
Caskk is an SKK-style Japanese input plugin for Vim that uses SKK dictionaries
for conversion.
It also supports conversion based on verb and adjective conjugation.
It is easy to configure for AZIK users.

------------------------------------------------------------------------------
PREREQUISITE                                                *caskk-prerequisite*

CI tests Vim 9.1.1826 and HEAD.
Install Caskk on Vim's `runtimepath`, then start with |caskk-example|.

------------------------------------------------------------------------------
EXAMPLE                                                          *caskk-example*

This example extends standard romaji input and uses `<C-J>` to toggle the IME.

For Vim9 script, use the following configuration.
>vim9
    vim9script

    import autoload 'caskk.vim' as Caskk

    # Add special sequences to standard romaji input
    Caskk.RegisterInputScheme({
      base: 'roman',
      name: 'roman',
      specials: {
        'z-': '〜',
        'z=': '＝',
        'z ': '　',
        'z/': '・',
        'z[': '『',
        'z]': '』',
      }
    })

    Caskk.Config({
      dictionaries: [
        {path: '/path/to/SKK-JISYO.verb-adjective', encoding: 'utf-8'},
        {path: '/path/to/SKK-JISYO.L',              encoding: 'euc-jp'},
      ],
      state_path: expand('$XDG_STATE_HOME/caskk/state.jsonl'),
      candidate_select_keys: ['1', '2', '3', '4'],
      sticky_key: ';',
      affix_key: ';;',
      mappings: {
        "\<Space>": 'NextCandidate',
        "\<C-N>":   'NextCandidate',
        "\<C-P>":   'PreviousCandidate',
        "\<C-M>":   'Commit',
        '/':        'AbbreviationMode',
        "'":        'KatakanaMode',
        '#':        'HalfwidthKatakanaMode',
        '@':        'FullwidthAlphanumericMode',
        'p':        'TogglePin',
        'P':        'ToggleDemote',
        "\<C-H>":   'DeleteUserEntry',
        "\<Tab>":   'NextCompletion',
        "\<S-Tab>": 'PreviousCompletion',
        "\<C-E>":   'CancelCompletion',
      },
      highlight: {
        preedit: {
          term: 'reverse,bold', cterm: 'reverse,bold', gui: 'reverse,bold',
        }
      },
    })

    # Toggle the IME
    inoremap <silent> <C-J> <ScriptCmd>Caskk.Toggle('roman')<CR>
    cnoremap <silent> <C-J> <ScriptCmd>Caskk.Toggle('roman')<CR>

    # Reconvert
    nnoremap <Leader>r <ScriptCmd>Caskk.Reconvert()<CR>
<

INTERFACE                                                      *caskk-interface*

------------------------------------------------------------------------------
HOOKS                                                              *caskk-hooks*

Caskk provides these autocommands.
You can use them as follows.

>
    autocmd User CaskkPreeditStart echo "Preedit started"

CaskkEnable                                                  *caskk-hook-enable*
    Fires when Caskk is enabled in the affected buffer.

CaskkDisable                                                *caskk-hook-disable*
    Fires when Caskk is disabled in the affected buffer.

CaskkInputModeChanged                            *caskk-hook-input-mode-changed*
    Fires when the input mode changes, for example from hiragana to katakana.

CaskkPreeditStart                                     *caskk-hook-preedit-start*
    Fires when you start entering a reading for conversion.

CaskkPreeditEnd                                         *caskk-hook-preedit-end*
    Fires when conversion is completed or cancelled.

CaskkConversionStart                               *caskk-hook-conversion-start*
    Fires when the first conversion candidate is previewed.

CaskkConversionEnd                                   *caskk-hook-conversion-end*
    Fires when candidate selection ends through commit, cancellation, or
    exhaustion.

CaskkCompletionStart                               *caskk-hook-completion-start*
    Fires when the reading completion list opens.

CaskkCompletionEnd                                   *caskk-hook-completion-end*
    Fires when the reading completion list closes.

CaskkRegistrationStart                           *caskk-hook-registration-start*
    Fires when the dictionary registration field opens.

CaskkRegistrationEnd                               *caskk-hook-registration-end*
    Fires when dictionary registration is completed or cancelled and the
    result is applied at the original input position.

==============================================================================
APIS                                                                *caskk-apis*

Caskk provides APIs for input and reconversion.
In legacy Vim script, call them as follows.
>vim
    call caskk#Enable('roman')
<

In Vim9 script, call them as follows.
>vim9
    vim9script
    import autoload 'caskk.vim' as Caskk

    Caskk.Enable('roman')
<

Caskk.Config(options)                                             *caskk-config*
    Configures Caskk and loads the system dictionaries.
    See |caskk-configuration| for details.
    Omitted options return to their defaults. Pass {} to reset all settings.
    Invalid options raise an error and leave the previous configuration in
    place.

Caskk.RegisterInputScheme(definition)              *caskk-register-input-scheme*
    Registers or updates a named input scheme.
    See |caskk-register-input-scheme-definition| for details.

Caskk.Enable(name)                                                *caskk-enable*
    Enables Caskk input in the current buffer or supported command line.

Caskk.Disable()                                                  *caskk-disable*
    Disables Caskk input and restores the previous mappings.

Caskk.Toggle(name)                                                *caskk-toggle*
    Toggles Caskk input.

Caskk.IsEnabled() → bool                                      *caskk-is-enabled*
    Returns whether Caskk input is enabled.

Caskk.Reconvert() → bool                                    *caskk-reconversion*
    In Normal mode, reconverts a recently converted word whose text overlaps
    the cursor. Returns true when reconversion starts.

Caskk.LoadState()                                             *caskk-load-state*
    Loads registered words, learned history, and ranking preferences from
    state_path.

Caskk.SaveState()                                             *caskk-save-state*
    Saves the current user state to state_path.

Caskk.ExportUserDictionary(path)                  *caskk-export-user-dictionary*
    Exports registered words as a UTF-8 SKK dictionary.

Caskk.GetInputScheme(name) → CompiledScheme             *caskk-get-input-scheme*
    Returns the compiled form of a registered input scheme.

Caskk.GetDictionaryLoadStatus() → dict<string>    *caskk-dictionary-load-status*
    Returns the dictionary loading status (loading, ready, or error) and error
    details.
    Large dictionaries load in the background.
    During the initial load, dictionaries can become available as they finish
    loading.
    On reload, Caskk uses the previous dictionaries until the new ones are
    ready.

Caskk.OpenRegistration()                               *caskk-open-registration*
    Opens the dictionary registration UI for the pending word.

Caskk.CompleteRegistration(text [, annotations])   *caskk-complete-registration*
    Completes dictionary registration with a candidate body and optional
    annotations.

Caskk.CancelRegistration()                           *caskk-cancel-registration*
    Cancels registration of the pending word.

Caskk.GetRegistrationRequest() → Request or null_object
                                                    *caskk-registration-request*
    Returns information about the pending word.
    Returns null_object if there is no pending request.
    The string fields are reading, okuri (the full suffix), exact_okuri (the
    first character of the suffix), and lookup_key (the dictionary lookup
    key).

CONFIGURATION                                              *caskk-configuration*

Caskk.Config(options) takes a dictionary keyed by the option names below. For
example, call Caskk.Config({sticky_key: ";", mode_popup: false}).
Each call resets omitted options to their defaults.
All keys are optional. The pseudocode below marks optional keys with ?.

>
    options: {
      sticky_key?: string,
      affix_key?: string,
      keyboard_layout?: 'US' | 'JIS',
      keyboard_layout_overrides?: dict<string>,
      mappings?: dict<string>,
      dictionaries?: list<{path: string, encoding: string}>,
      state_path?: string,
      small_tsu_okuri_as_t?: bool,
      prefer_direct_okuri_nashi_learning?: bool,
      keep_preedit_on_backspace?: bool,
      undo_revert_to_reading?: bool,
      persist_input_mode?: bool,
      registration_auto?: bool,
      registration_prefill?: bool,
      registration_inline?: bool,
      register_mode_conversions?: bool,
      completion_min_length?: number,
      candidate_popup?: bool,
      candidate_select_keys?: list<string>,
      mode_popup?: bool,
      mode_popup_labels?: dict<string>,
      mode_popup_markers?: dict<string>,
      mode_popup_time?: number,
      highlight?: {preedit?: dict<string>},
    }
<

sticky_key                                             *caskk-config-sticky-key*
    Type: string, default: ''
    Treats the following key as modified input, like an uppercase key in SKK.
    You can use a named key such as '<F9>'.

affix_key                                               *caskk-config-affix-key*
    Type: string, default: ''
    Assigns a key sequence for entering > in prefix and suffix lookups.
    With {sticky_key: ';', affix_key: ';;'}, type ;;teki to look up >てき or
    ;hi;; to look up ひ>.

keyboard_layout                                   *caskk-config-keyboard-layout*
    Type: string, default: 'US'
    Selects the keyboard layout. The accepted values are US and JIS.

keyboard_layout_overrides               *caskk-config-keyboard-layout-overrides*
    Type: dictionary, default: {}
    Overrides individual unshifted-to-shifted symbol mappings.
    For example, keyboard_layout_overrides: {'1': '?'} makes ? the shifted
    form of 1. If 1 maps to the consonant k, typing ?a is equivalent to typing
    Ka.

mappings                                                 *caskk-config-mappings*
    Type: dictionary, default: {}
    Assigns keys to input mode changes and conversion operations.
    See |caskk-mapping-actions|.

dictionaries                                         *caskk-config-dictionaries*
    Type: list, default: []
    Lists SKK dictionaries in priority order. Each entry requires path and
    encoding.

>vim9
    dictionaries: [
      {path: '/path/to/SKK-JISYO.utf8', encoding: 'utf-8'},
      {path: '/path/to/SKK-JISYO.L',    encoding: 'euc-jp'},
    ],
<

state_path                                             *caskk-config-state-path*
    Type: string, default: ''
    Sets the user state file. Caskk loads it on first enable and automatically
    saves it when state changes and when Vim exits. An empty path keeps state
    in memory.

small_tsu_okuri_as_t                         *caskk-config-small-tsu-okuri-as-t*
    Type: boolean, default: true
    Uses t as the SKK lookup consonant for okuri beginning with っ. For
    example, a lookup for おも*っ uses the t-row key.
    Set this to false to use x.

prefer_direct_okuri_nashi_learning
                               *caskk-config-prefer-direct-okuri-nashi-learning*
    Type: boolean, default: true
    Ranks direct selections without okuri ahead of learned selections for the
    same stem with okuri.
    If you convert いえ to 家 and then いえ*る to 癒える, 家 still ranks ahead
    of 癒え for いえ. Selecting 癒え directly for いえ then moves it ahead of
    家.

keep_preedit_on_backspace               *caskk-config-keep-preedit-on-backspace*
    Type: boolean, default: true
    Keeps preedit active when you delete the last character of the reading.

undo_revert_to_reading                     *caskk-config-undo-revert-to-reading*
    Type: boolean, default: true
    Adds an undo step that restores the reading before removing it.
    Set this to false to undo the whole conversion in one step.

persist_input_mode                             *caskk-config-persist-input-mode*
    Type: boolean, default: false
    Keeps the input mode when leaving and re-entering Insert mode in the same
    buffer.

registration_auto                               *caskk-config-registration-auto*
    Type: boolean, default: true
    Automatically opens dictionary registration when conversion candidates run
    out.

registration_prefill                         *caskk-config-registration-prefill*
    Type: boolean, default: true
    Prefills the registration field with the reading.

registration_inline                           *caskk-config-registration-inline*
    Type: boolean, default: true
    Uses an inline popup for dictionary registration.
    Set this to false to use a separate registration window.

register_mode_conversions               *caskk-config-register-mode-conversions*
    Type: boolean, default: true
    Registers the results of katakana and fullwidth alphanumeric conversions
    in the user dictionary.

completion_min_length                       *caskk-config-completion-min-length*
    Type: positive integer, default: 2
    Sets the minimum reading length for completion.

candidate_popup                                   *caskk-config-candidate-popup*
    Type: boolean, default: true
    Shows conversion candidates in a popup.
    A ★ marks pinned candidates, and a ↓ marks demoted candidates.

candidate_select_keys                       *caskk-config-candidate-select-keys*
    Type: list, default: []
    Assigns label keys for choosing conversion candidates.
    By default, you move through candidates one at a time.
    With ['1', '2', '3'], each page shows up to three candidates. Use 1, 2, or
    3 to select one.

    With an empty list, Caskk hides the labels and moves through candidates
    one at a time.

mode_popup                                             *caskk-config-mode-popup*
    Type: boolean, default: true
    Shows the current input mode in a popup near the cursor.

mode_popup_labels                               *caskk-config-mode-popup-labels*
    Type: dictionary, default: {hiragana: 'あ', abbreviation: 'ab',
    katakana: 'ア', halfwidth_katakana: 'ｱ', fullwidth_alphanumeric: 'Ａ'}
    Sets the labels for the input modes shown in the popup.

mode_popup_markers                             *caskk-config-mode-popup-markers*
    Type: dictionary, default: {modified: '▽', candidate: '▼'}
    Sets the popup markers for editing a reading and selecting a conversion
    candidate.

mode_popup_time                                   *caskk-config-mode-popup-time*
    Type: nonnegative integer, default: 0
    Sets how many milliseconds the mode popup stays visible. With 0, it stays
    visible until the cursor moves or input ends.

highlight (preedit)                                     *caskk-config-highlight*
    Type: dictionary, default:
    {preedit: {term: 'underline', cterm: 'underline', gui: 'underline'}}
    Sets highlighting for preedit text.
    Accepts |highlight-args| attributes and string values for ctermfg,
    ctermbg, ctermul, guifg, guibg, guisp, font, start, and stop.

    Example: {highlight: {preedit: {gui: 'bold', guifg: '#123456'}}}

------------------------------------------------------------------------------
MAPPING ACTIONS                                          *caskk-mapping-actions*

The mappings dictionary maps keys to action names. For example, mappings:
{"\<Space>": "NextCandidate"} assigns Space to start conversion or advance to
the next candidate. Use Vim keycodes such as "\<Space>" for special keys.
The available actions are listed below.
No action keys are assigned by default.

NextCandidate                                      *caskk-action-next-candidate*
    Starts conversion or advances to the next candidate.

PreviousCandidate                              *caskk-action-previous-candidate*
    Moves to the previous candidate. Moving back from the first candidate
    restores the editable reading.

Commit                                                     *caskk-action-commit*
    Commits the conversion.

NextCompletion                                    *caskk-action-next-completion*
    Opens the completion popup and selects the first item, or advances to the
    next suggestion.

PreviousCompletion                            *caskk-action-previous-completion*
    Moves to the previous reading suggestion. Moving back from the first item
    clears the selection. Moving back with no selection selects the last item.

CancelCompletion                                *caskk-action-cancel-completion*
    Closes completion and restores the editable reading.

OpenRegistration                                *caskk-action-open-registration*
    Opens dictionary registration for the pending word.
    You can use this action when automatic registration is disabled.

TogglePin                                              *caskk-action-toggle-pin*
    Toggles pinning for the selected candidate. Pinned candidates rank first.
    Each reading can have one pinned candidate.

ToggleDemote                                        *caskk-action-toggle-demote*
    Toggles demotion for the selected candidate. Demoted candidates rank last.
    Each reading can have multiple demoted candidates.

DeleteUserEntry                                 *caskk-action-delete-user-entry*
    Opens a confirmation prompt to delete the selected user entry.
    This action is unavailable on the command line and during reading
    completion.

AbbreviationMode                                *caskk-action-abbreviation-mode*
    Switches to abbreviation mode, where typed text is used directly as the
    dictionary reading.

KatakanaMode                                        *caskk-action-katakana-mode*
    Switches to fullwidth katakana input. It can also commit the current
    hiragana preedit as fullwidth katakana.

HalfwidthKatakanaMode                     *caskk-action-halfwidth-katakana-mode*
    Switches to halfwidth katakana input. It can also commit the current
    hiragana preedit as halfwidth katakana.

FullwidthAlphanumericMode             *caskk-action-fullwidth-alphanumeric-mode*
    Switches to fullwidth alphanumeric input. It can also commit the
    alphanumeric text being edited in fullwidth form.

------------------------------------------------------------------------------
Caskk.RegisterInputScheme(definition)   *caskk-register-input-scheme-definition*

Caskk.RegisterInputScheme(definition) takes a dictionary defining an input
scheme.
To define one from scratch, supply name, consonants, and combinations. To
extend a built-in scheme, supply name, base, and the rules you want to change.
The pseudocode below marks optional fields with ?. Without base, both
consonants and combinations are required.

>
    definition: {
      name: string,
      base?: string,
      consonants?: dict<string | null>,
      combinations?: dict<string | null>,
      specials?: dict<string | null>,
      n_fallback?: bool,
    }
<

Use v:null to remove an inherited rule.

name                                                         *caskk-scheme-name*
    The scheme name as a string. Pass this name to Enable() or Toggle().

base                                                         *caskk-scheme-base*
    Set this to 'roman' or 'azik' to inherit a built-in definition. You can
    override individual rules in consonants, combinations, and specials.
    Omit this field when defining a complete scheme from scratch.

consonants                                             *caskk-scheme-consonants*
    Maps key sequences to consonant identifiers. For example, with sh: 'sy',
    typing sha produces しゃ. The identifiers also include direct symbols for
    ん and っ. See |caskk-kana-table|.
    A key sequence usually maps to one consonant identifier. You can prefix it
    with T to insert っ. For example, with kk: 'Tk', typing kka produces っか.

combinations                                         *caskk-scheme-combinations*
    Defines vowels and other output after a consonant from consonants. For
    example, with s: 'a', typing ks produces か. Longer output sequences are
    allowed if they begin with a vowel. See |caskk-kana-table|.
    Use * to mark a latent okuri boundary. With p: 'a*imasu', typing kp
    produces かいます. Typing KP or ;k;p starts conversion with the reading
    か*います.

specials                                                 *caskk-scheme-specials*
    Maps key sequences directly to output text. For example, with nn: 'ん',
    typing nn produces ん. Specials take precedence over consonant and
    combination rules.

    Use * in the output to mark a latent okuri boundary.
    With mm: 'あ*う', Mm starts a reading of あう, MM starts conversion with
    あ*う, DakiMm starts conversion with だき*あう, and DakimM starts
    conversion with だきあ*う.

    Write '\*' for a literal asterisk and '\\' for a literal backslash.

n_fallback                                             *caskk-scheme-n-fallback*
    Defaults to true. Controls whether a lone n becomes ん before a consonant
    or when input is committed.

Use ordinary characters or Vim keycodes such as "\<C-K>" for keys.
Each output may contain one unescaped '*'.

CONJUGATION                                                  *caskk-conjugation*

Register an adjective or verb with a conjugation tag to convert it with
multiple okuri endings.
For example, the dictionary entry 'おも /思;@verb-5-w/' converts おも*う to
思う and おも*わない to 思わない.
The adjective entry 'うつくし /美し;@adj/' supports 美しく and 美しか.
Invalid endings such as うつくし*べ produce no candidate from that entry.

Use tag completion to find the conjugation tag during registration.

To register from おも*う, enter 思 in the registration field and press Tab.
Caskk appends ;@ and opens tag completion. Press Tab to select a tag.
Type part of a tag to narrow the completion list.

A UTF-8 SKK dictionary of tagged verbs and adjectives is also available.
skk-verb-adjective-dictionary
https://github.com/NI57721/skk-verb-adjective-dictionary

BASIC USE                                                      *caskk-basic-use*

------------------------------------------------------------------------------
COMPLETION                                                    *caskk-completion*
    With |caskk-config-candidate-popup| enabled, suggestions appear when the
    reading reaches |caskk-config-completion-min-length|.
    NextCompletion opens the list or advances the selection.
    PreviousCompletion moves back.

------------------------------------------------------------------------------
REGISTRATION                                                *caskk-registration*
    Caskk opens inline registration by default when no candidates are found or
    when you advance past the last one.
    Press Enter to register or Esc to cancel.
    The first ';' separates the body from the annotation (body;annotation).

------------------------------------------------------------------------------
COMMAND LINE                                                *caskk-command-line*
    Enable Caskk separately in :, /, or ?. Dictionary registration, reading
    completion, and reconversion are available for Insert-mode input.

------------------------------------------------------------------------------
ABBREVIATION MODE                                      *caskk-abbreviation-mode*
    Uses typed text directly as the dictionary reading.

------------------------------------------------------------------------------
NUMERIC CONVERSION                                    *caskk-numeric-conversion*
    Caskk also searches dictionary keys with digit runs replaced by '#'.
    Candidate placeholders are #0 (ASCII), #1 (fullwidth), #2 (kanji digits),
    #3 (positional kanji), #5 (daiji), #6 (Roman numerals), and #8 (comma
    grouping).
    For example, the dictionary entry '#:# /#0時#0分/' converts '12:34' to
    '12時34分' in abbreviation mode.
